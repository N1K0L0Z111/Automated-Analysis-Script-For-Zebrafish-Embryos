# Automated-Analysis-Script-For-Zebrafish-Embryos
This is the automated ImageJ analysis script for zebrafish embryos in python and java.

The scripts will be for two assays: Caspase and TUNEL methods. Each will have to types of scripts, java and python. Java will be used to directly use ImageJ's functionalities and python will compile the results gather by java to further calculations and output csv file with all the necessary parameters for the analysis.
